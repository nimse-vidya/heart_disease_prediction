# ❤️ AI-Based Heart Disease Prediction & Risk Analysis System

## 📌 About the Project
The **AI-Based Heart Disease Prediction & Risk Analysis System** is a machine learning project that analyzes health-related dataset features and compares multiple machine learning classification algorithms to explore patterns associated with heart disease.

The project uses Python, data analysis, visualization, and machine learning techniques to train and evaluate models.

## 🎯 Objectives
- Analyze heart disease dataset features.
- Perform data cleaning and preprocessing.
- Visualize patterns using Exploratory Data Analysis (EDA).
- Train multiple machine learning algorithms.
- Compare models using evaluation metrics.
- Identify important features using feature importance analysis.
